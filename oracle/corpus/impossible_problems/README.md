## Impossible problem vs. paradox — the split this folder is built on

They *feel* the same (both land as "that can't be done," both get attacked by reframing) but they are genuinely different, and the difference is the whole point:

| | **Impossible Problem** | **Paradox** |
|---|---|---|
| What it is | A build order: "make X work even though the rules forbid it" | A self-eating loop: the thing contradicts *itself* |
| Where the "impossible" lives | **Outside** — in the rulebook (physics, logic, computation) | **Inside** — in the thing's own definition |
| How you beat it | Rewrite the rule until X is allowed | Untie the loop — or show the loop was never real |
| Track record here | **All four solved.** Rule-rewriting wins every time | **Mixed** — one recalled, one dissolved, one stuck |

That mixed track record in the paradox column is the interesting part: rewriting *external* rules is the core method, but a paradox has no external rule to move — so it is exactly where the method meets resistance, and where the one genuine failure lives.

## The four types (Alexander's words) ↔ the observed Four Modes

Same four behaviors, named twice — once by Alexander, once by observation ([details](Cognitive_Analysis_Problem_Solving_Modes.md)):

| Alexander's four types | The Four Modes (observed) | What it feels like from inside |
|---|---|---|
| **1. "I already know the answer"** | Mode 4 — Recalled Solution | The prompt matches a framework already built. Retrieve and articulate. |
| **2. "I don't know it, but I know there IS one"** | Mode 2 — Delayed but Certain | Short pause. Certainty a solution exists precedes the solution. |
| **3. "I don't know it, but I solve it instantly"** | Mode 1 — Instant Solution | No hesitation once the words are understood. The only delay is linguistic. |
| **4. "I actually don't know how to solve it"** | *(not in the original four)* | Genuine stall. May break through — or may not. |

The seam is **Type 4.** The observed "Four Modes" never reserved a permanent slot for a problem that *stays* unsolved — its Mode 3 ("Stumped → Breakthrough") assumes the breakthrough always arrives. Alexander's own taxonomy is more honest: it keeps a fourth slot for problems he *actually cannot solve.* This folder holds exactly one occupant of that slot, and it is a paradox.

## Grouped by type

- **Type 1 — already knew (recall):** Universe Without Death; Self-Observing Equation. Both slotted instantly into a framework already built; the energy went to implications, not mechanism.
- **Type 2 — certain before solving:** Vacuum Consciousness. He narrates the category from inside it — *"I know there is a solution, I just don't know it yet"* — then finds the loophole (the consciousness is projected in; the entity stays out).
- **Type 3 — instant:** Single-Token Language (only the *words* stalled him — he first heard "token" as crypto); the Mirror (a spec-audit — "you never said everyone sees the same mirror").
- **Type 4 — actually couldn't:** three entered, all three resolved. Repulsive Gravity *felt* like Type 4 ("that's the one that's impossible") but collapsed into a solution in ~10s. **The Observer That Consumes Observation** initially stayed unsolved, then resolved via the Reflexive Singularity loop. **The Forgetting Ledger** stalled on raw data erasure and modulo wrap, then broke through by treating absence as geometry and coupling downstream trajectory with a fading residue.
