LaunchDarkly is the runtime control platform for releases, AI behavior, and customer experiences in real time with no redeploys required. As the pioneer of feature management, LaunchDarkly introduced a new way for engineering teams to separate code deployment from feature release, allowing organizations to innovate faster while reducing risk in production.

Ratings/Rewards

Our rewards are based on severity per CVSS (the Common Vulnerability Scoring Standard). However, it is important to note that in some cases a vulnerability priority will be modified due to its likelihood or impact. In any instance where an issue is downgraded, a full, detailed explanation will be provided to the researcher - along with the opportunity to appeal, and make a case for a higher priority.
